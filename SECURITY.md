# Security

RBEK is designed around governed execution and fail-closed behavior.

## Public repository boundary

This repository does not publish:

- private signing authority;
- commercial entitlement issuer tooling;
- operator entitlement tooling;
- private keys;
- real customer kits;
- internal customer or GTM data;
- internal governance evidence.

The public CLI/runtime is distributed from the official RBEK release host.

## Reporting security issues

Do not publish suspected security vulnerabilities in a public GitHub issue.

Contact:

`info@rbekplatform.com`

Include enough detail to reproduce the issue without including customer secrets
or credentials.
