# Install RBEK Developer

## Official installer

```bash
curl -fsSL https://releases.rbekplatform.com/cli/stable/install.sh | bash
```

The installer resolves the current stable version from the official RBEK
release channel and verifies the release archive before installation.

## Verify installation

```bash
rbek-cli --version
```

Expected current stable output:

```text
RBEK 0.2.0
```

## Release channel

Public stable artifacts are served from:

```text
https://releases.rbekplatform.com/cli/stable/
```

## Developer access

RBEK Developer does not require a paid commercial entitlement.

Commercial Team and Enterprise access use separate organization-level
entitlement and deployment controls.
